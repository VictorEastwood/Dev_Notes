# Linux 串口使用技巧

本文整理串口设备识别、占用排查和通信测试的常用方法。安装与配置步骤见 [Linux 串口驱动安装与配置](Linux_Serial_Driver_Installation.md)。

## 1. 查看设备是否被识别

### 查看 USB 设备

插入串口设备后，查看 USB 设备列表：

```bash
lsusb
```

CH340 设备的输出示例：

```text
Bus 003 Device 012: ID 1a86:7523 QinHeng Electronics CH340 serial converter
```

### 查看串口设备节点

查看 `/dev/` 下的设备：

```bash
ls /dev/
```

例如，原文使用的 CH341 驱动对应的设备节点为：

```text
ttyCH341USB0
```

> USB 设备信息可用于确认硬件是否被识别；串口通信时，需要选择实际生成的设备节点。

## 2. 排查串口占用

### 查看占用进程

使用 `lsof` 检查串口是否被其他进程占用：

```bash
lsof /dev/ttyS*
```

也可以检查具体设备，将路径替换为实际使用的串口：

```bash
lsof /dev/ttyUSB0
```

### 查看内核日志

结合内核日志查看设备识别和驱动相关信息：

```bash
dmesg
```

### 留意可能占用串口的服务

- `brltty`：提供盲文显示支持，可能占用某些串口设备。
- `ModemManager`：排查占用问题时，也可检查该服务。

> 如果仍需要盲文支持，应保留相关辅助功能。有关 `brltty` 的处理步骤，参见安装与配置文档。

## 3. 使用回环测试检查通信

### 设置调试工具

在已安装的 CuteCom 中，选择实际的串口设备（例如 `/dev/ttyCH341USB0`），并设置以下参数：

| 参数 | 示例值 |
| --- | --- |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None（无） |
| 停止位 | 1 |
| 流控 | None（无） |

### 执行回环测试

1. 将 CH340 设备的 **TXD 与 RXD 短接**。
2. 打开对应串口，输入字符并发送。
3. 检查是否收到相同字符的回显。

> 测试时关闭调试工具的本地回显，避免将输入内容的本地显示误认为设备收到的数据。

## 4. 常用串口调试工具

| 工具 | 特点 |
| --- | --- |
| `cutecom` | 图形界面串口调试工具 |
| `minicom` | 命令行串口工具 |

| `picocom` | 轻量级串口工具 |
